# Autonomous Research Agent

An autonomous AI-powered research agent built using:

- FastAPI
- LangGraph
- LangChain
- Groq
- Tavily
- BeautifulSoup

## Features

- Research planning
- Web search integration
- URL fetching
- Text extraction
- Autonomous reasoning
- Working memory

## Run Project

```bash
cd BACKEND
uvicorn app.main:app --reload
